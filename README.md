# Mealify - Restaurant Website 🍔

A professional and delicious restaurant landing page designed to showcase food menus, chefs, and restaurant features with a modern touch.

## 🚀 Features
* **Dark Mode Support:** Includes a dedicated dark theme for a better viewing experience.
* **Fully Responsive:** Perfectly optimized for mobile, tablet, and desktop screens using Media Queries.
* **Modern UI:** Features clean sections for Home, About, Menu, and Contact.
* **Smooth Animations:** Interactive hover effects and transitions.

## 🛠️ Technologies Used
* **HTML5:** For semantic and structured content.
* **CSS3:** Advanced styling including Flexbox, Grid, and Custom Variables for Dark Mode.
* **Media Queries:** For ensuring a seamless responsive design across all devices.
